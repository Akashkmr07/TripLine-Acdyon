# Tripline

A visual travel planner landing page built with React and Tailwind CSS.

## The Idea
"Your entire trip. On one line."

Tripline takes scattered bookings, flights, and itineraries and visualizes them on a single timeline.

## Tech Stack
- **Framework**: React, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Smooth Scrolling**: Lenis (@studio-freight/lenis)
- **Icons**: Lucide React

## Setup and Installation

1. Install dependencies
```bash
npm install
```

2. Run the development server
```bash
npm run dev
```

3. Build for production
```bash
npm run build
```

## Features
- Clean, minimalistic layout using the Outfit font.
- Smooth scrolling implemented with Lenis.
- Scroll-linked animations using Framer Motion (like the timeline drawing as you scroll).
- Code-based UI mockups (built with Tailwind rather than static images).
